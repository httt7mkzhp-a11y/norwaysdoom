# Gjennomgangskø for kostnadsutvikling

- `queue/<prosjekt>.json`: automatisk uttrekk (kandidattall med tekstutdrag, side og kilde-URL). **Aldri publisert.** Genereres av `python3 pipeline/projects_build.py`.
- `approved/<prosjekt>.json`: manuelt godkjente poster. **Kun disse publiseres** (til `public/data/projects.json`).

Se [docs/prosjekter.md](../../docs/prosjekter.md) for format og arbeidsflyt.
